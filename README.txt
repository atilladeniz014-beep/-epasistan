ATİLLA AI — ilk arayüz prototipi

Bu paket şu an görsel tasarım ve tıklanabilir arayüz demosudur.
Gerçek yapay zekâ cevapları, sesli sohbet ve internetten benzer görsel/ürün araması henüz bağlı değildir.

iPhone'da ana ekrana eklemek için:
1. Bu klasörü HTTPS destekleyen bir web barındırma servisine yükle.
2. Safari'de yayınlanan adresi aç.
3. Paylaş düğmesi > Ana Ekrana Ekle.

Güvenlik:
- API anahtarını HTML/JavaScript içine koyma.
- Gerçek AI ve görsel arama için API anahtarlarını sunucuda tutan bir backend gerekir.
- Kullanıcı fotoğrafları açık izin olmadan saklanmamalı veya paylaşılmamalıdır.
